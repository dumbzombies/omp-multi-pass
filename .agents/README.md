# Memory Bank

Persistent project memory for omp-multi-pass. Read before substantive work.

## Files

- `memory.md` — durable knowledge: stack, architecture, invariants, gotchas.
  Append `## <YYYY-MM-DD> — <topic>` entries; never silently delete history.
  No secrets, tokens, or private URLs.
- `state.md` — always-current status: Goal, Today's progress, Blockers, Next actions.
- `.agents/AGENTS.md` — read order and maintenance rules.
- Root `AGENTS.md` — stable repo guidance for every tool.

## Session flow

1. Read `.agents/state.md`, then `.agents/memory.md`.
2. Follow root `AGENTS.md`.
3. After a large verified change, update `state.md` and append to `memory.md`.
